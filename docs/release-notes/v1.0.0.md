# Audial Synth 1.0.0

First release.

- GPLv3 fork of [Vital](https://github.com/mtytel/vital) 1.0.6: the full wavetable synth engine,
  modulation matrix, effects chain and wavetable editor, unchanged from upstream.
- New Resynth panel: drop a one-shot sample (up to 20 seconds) and the Audial hosted engine
  analyses it and returns a patch, loaded straight into the synth as an editable preset — every
  oscillator, envelope and effect stays yours to tweak afterward. Requires an Audial subscription.
- Credentials are just a user id and API key, entered once in the Resynth panel; the API base URL
  is baked into the build.
- macOS build: VST3, Audio Unit and standalone app.

## Install

1. Download `AudialSynth-macOS.zip` below and unzip it.
2. Move `AudialSynth.vst3` to `~/Library/Audio/Plug-Ins/VST3` and `AudialSynth.component` to
   `~/Library/Audio/Plug-Ins/Components`, or run the standalone `AudialSynth.app` directly.
3. First launch: right-click the app (or plug-in host) and choose Open, since this build is not
   yet notarized.

## Installing this unsigned build

This release is not yet signed with an Apple Developer ID, so macOS Gatekeeper will block it on first launch. After copying the bundles into place, run once in Terminal:

```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/AudialSynth.vst3 ~/Library/Audio/Plug-Ins/Components/AudialSynth.component
```

(or right-click → Open the standalone app once). A signed and notarized build will replace this release.
